# Case 02 — Social Media Engagement Report

**Industry:** Media · **Difficulty:** ROOKIE

## The situation

A lifestyle brand's marketing lead posts across Instagram, TikTok, and X and has never looked at the numbers properly. "I feel like TikTok is where it is happening but I want to see it. Build me something I can show the founder next week."

## The data

One sheet, `posts`, about 600 rows covering six months.

| column | example | notes |
|---|---|---|
| post_date | 2025-05-11 | |
| platform | tiktok | instagram, tiktok, x |
| format | video | image, video, carousel, text |
| impressions | 18400 | how many people saw it |
| likes | 920 | |
| comments | 47 | |
| shares | 61 | |
| follows | 12 | new follows attributed to the post |

## Deliverables

1. **Engagement rate.** Define it as `(likes + comments + shares) / impressions`. Add it as a column.
2. **Which platform, which format.** A chart comparing average engagement rate by platform, and a second chart by format. Pick the chart types deliberately and say why in one line each.
3. **The recommendation.** One paragraph the marketing lead can read to the founder: where to focus, backed by two numbers from your charts. Include one caveat about what the data cannot tell you (for example, whether TikTok impressions and Instagram impressions are counted the same way).

## What "done" looks like

Two charts, an engagement-rate column, and a paragraph. The caveat matters as much as the recommendation.
